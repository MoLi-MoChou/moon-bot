# 发版前真机检查

CI 只跑单元测试和 Linux 上的浏览器端到端。窗口外框、输入法、高 DPI、安装与升级这些，只有真机能测。每次发版前，维护者在 Windows 上做一遍；改动涉及 macOS 时，在 macOS 上也做一遍。

每一项记「通过 / 不通过 / 备注」。不通过的截图，抄下错误原文，开 Issue。结果贴在 Release PR 的评论里。

## 8. Desktop 和 Web 同时开

`pnpm --filter moon-bot run web` 起的服务和窗口里的服务读写同一个数据目录，两者的写者锁只让一个动手。

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| 8.1 | Desktop 开着；另开终端运行 `MOON_BOT_PASSWORD=<密码> pnpm --filter moon-bot run web` | Web 打开密码页，输入密码后进团队 | |
| 8.2 | 在 Web 里看团队 | 同一个团队；Bot 列表上方有只读说明 | |
| 8.3 | 在 Web 里改一个 Bot 的名字 | 被拒绝，提示在另一个实例里打开 | |
| 8.4 | 在 Desktop 里改名 | Web 几秒内跟着变 | |
| 8.5 | 退出 Desktop，在 Web 里再改名 | Web 接手，改名成功 | |
| 8.6 | 重新打开 Desktop | Desktop 变成只读，显示说明 | |

## 10. 桌面应用（Windows）

10.7 和 10.8 要在 Release 发布、工作流传完安装包之后做：Release 里要有安装包、它的 `.blockmap` 和 `latest.yml`。上一个发布版本没有安装包时，跳过这两项。

| # | 步骤 | 期望 | 结果 |
|---|---|---|---|
| 10.1 | 运行安装包，选安装位置，安装 | 不要管理员权限；只装给当前用户；开始菜单里有 Moon Bot | |
| 10.2 | 第一次打开：选数据位置和总工作区 | 新装是空团队，Main Bot 请你选模型 | |
| 10.3 | 给一个 Bot 发消息；再打开设置 → 关于 Moon Bot | 收到回复；Moon Bot 一行写「随 Moon Bot 应用一起更新。」 | |
| 10.4 | 看窗口：拖标题栏，双击标题栏，点最小化、最大化、关闭；切换浅色和深色 | 没有系统边框；拖得动，双击会最大化，最大化后顶部没有缝；三个按钮都能用，底色和下面的界面一样；Windows 11 上侧栏透出 Mica，Windows 10 上标题栏和侧栏同色 | |
| 10.5 | 按 `Ctrl+Alt+B` | 侧栏收起，再按一次展开 | |
| 10.6 | 设置 → 通用 →「位置」：把总工作区换到另一个文件夹，给 Bot 发消息；再把数据位置换到一个空文件夹 | 总工作区换完，Bot 的下一轮在新文件夹里；数据复制完 App 自己重启，团队和对话都在，「位置」里是新的数据位置，旧文件夹还在 | |
| 10.7 | 装上一个发布版本的 App，打开它，等它提示新版本已经下载好，选「立即重启」 | App 关掉后自己装好新版并重新打开；关于页里是新版本号；团队都在 | |
| 10.8 | 再装一次上一个版本，等下载好的提示，选「稍后」，退出 App，等半分钟再打开 | 打开的是新版 | |
