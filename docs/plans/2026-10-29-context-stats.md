# 上下文数字：没有投影服务时仍能读

- 日期：2026-10-29
- 相关：[从 OpenBot 借鉴什么](2026-10-28-openbot-borrowing.md) 的 P1-8；[上下文与记忆](2026-10-09-context-and-memory.md)

## 为什么

上下文环读 `run-stats`。独立装配没有 `sessionProjections` 时，这个端点直接返回 `null`，环是空的。分段和管家已经会估算当前段用了多少 token、模型窗口有多大，只是没把这个数交给界面。

## 已定的行为

- 有 `sessionProjections` 时，`run-stats` 仍返回它的快照，不改字段。
- 没有时，对这个 Bot 当前聊天段估算：`contextPressure.projectedTokens` 是 `tokensOf` 的结果（先用量具，量具不可用再按正文估算）；`contextWindow` 是该段已路由模型的窗口，还没路由则用管家的默认窗口。
- 会话解不开、或一个 token 数都算不出来：仍返回 `null`。不编一个数。
- 不写入 `state.json`，不过 relay，不触发压缩。

## 不做什么

- 不做手动压缩。那要在没有正在跑的回合、没有未读投递时才接受，拒绝原因要说清，另写。
- 不拆上下文分类账，不显示压缩进度。
- 不把这个估算当成计费账本。用量页仍读自己的账。

## 已知限制

- 默认窗口是管家的默认值，不是用户选的模型窗口。模型还没路由到这一段时，百分比会偏小。
- 估算是上界，不是提供商回报的精确用量。
