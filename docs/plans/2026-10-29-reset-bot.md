# 重置 Bot：可组合的四件事，先列后果再确认

- 日期：2026-10-29
- 相关：`core/src/host/roster.ts`、`core/src/host/memory.ts`、`core/src/store/sessions.ts`、`core/src/client/bot-settings.tsx`、[长消息](2026-10-16-long-messages.md)、[上下文与记忆](2026-10-09-context-and-memory.md)

## 为什么

现在只能逐条删记忆（`memory-forget` 一次一条），没法一次清干净，也换不掉一个 Bot 的历史和身份。用户想「从头开始用这个 Bot」时没有入口。

难点在于**四种状态的后果差别很大**，混成一个「重置」按钮等于让用户闭眼删：

| 状态 | 存在哪 | 重置后 |
|---|---|---|
| 记忆 | `<home>/memory/bots/<id>/`（MEMORY.md + 话题） | 忘了所有事，身份设定还在 |
| 对话历史 | SQLite transcript + `state.bots[id].segments` | 上下文清空，像刚认识 |
| 群聊里说过的话 | `state.rooms[*].log` | 影响别的 Bot 和用户看到的历史 |
| 身份设定 | `state.bots[id]`（名字/角色/指令/模型/权限/头像/工作目录） | 相当于新 Bot，但保留 id 与群成员身份 |

## 已定的行为

一个动作，四个**可独立勾选**的部分，默认只勾「清空记忆」：

1. **清空记忆** — 该 Bot 的 MEMORY.md、全部话题、summary 一起清掉。
2. **重启对话（开新段）** — 让当前聊天换到一个新段，旧段仍可读。
3. **删除对话历史** — 它自己的聊天记录，以及在各群里它自己的隐藏会话。
4. **恢复默认设定** — 名字恢复默认、角色/指令清空、模型与思考强度回到默认、权限预设回到默认、头像回到字符形象、工作目录回到团队工作区。

### 二次确认

点「重置」先展开一个面板，**逐条列出将要删除/改动的内容**（按当前勾选实时变化），并说明不可恢复的部分。面板底部两句确认文案，必须点「确认重置」才执行。

不要求输入 Bot 名字：重置不是删除 Bot，身份还在，输入名字的门槛更适合删除。

### 不做什么

- 不删 Bot 本身（删除是另一件事，有它自己的入口和确认）。
- 不动群聊里**别人**说的话；只清它自己在群里的隐藏会话与记忆。
- 不动团队记忆（`memory/team/`）和群记忆（`memory/groups/`）：那是别处共享的，重置一个 Bot 不该连带清掉。
- 不做「撤销」。记忆按现有做法进 `memory/archive/`，但界面不提供恢复入口。
